# LAPA Architects: Crafted Connections

Build a premium, bold, mobile-first LAPA Architects construction/architecture website for Kerala and UAE. Use the attached LAPA logo as the real brand asset and incorporate its meaning: land patterns, architecture beginning with the land, and the four layers representing four founding friends. Follow the user's complete requested structure and copy: ticker, sticky blurred header, cinematic hero, about, six services, filterable 9-project masonry portfolio with project-detail modal, animated stats, moving testimonial carousel, CTA inquiry form opening WhatsApp with the provided variable placeholder number, floating WhatsApp button, and detailed footer. Make it feel luxury, minimal and architectural, using black #0A0A0A, construction yellow #FFC400, white, dark gray; Syne/Space Grotesk-like headings and Inter-like body. Add polished 3D-inspired motion, Framer Motion interactions, hover depth/image zoom, smooth scroll, responsive layout, icons, premium photography, dummy data. Do not use a generic local contractor template aesthetic.
